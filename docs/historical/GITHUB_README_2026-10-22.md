# Paper 1152 data and code

Risk-Informed Maintenance Decision Support for Mining Machine Cutters under Imperfect Wear Monitoring and Prognostic Uncertainty

Authors: Ivan V. Brovchenko, Evgeny B. Mazakov, Andrey V. Gurko and Kristina V. Matrokhina.

This tree contains the frozen source and statistical-analysis code for a model-based cutter-maintenance study. The complete evidence file is distributed as a release asset named `1152_DATA_CODE_RELEASE_2026-10-21.zip`. Suggested tag: `1152-2026-10-21-audit1`. Release creation and public availability have not been performed by this preparation operation. Replace these pre-publication instructions with the actual release link after publication.

## Complete evidence and scope

The full release contains 2,496 unique simulated episodes in eight frozen rows, exact source/configuration archives, retained runtime binaries, episode/action/statistical/numerical/resource records, analysis outputs and figure/table sources. It contains no field measurements. The ordinary source-tree ZIP automatically generated by GitHub is not the complete dataset: download the full release asset.

The policy is favourable versus B7 and B1 and unfavourable versus B4 under the specified model. Pointwise Wilson bounds inspected repeatedly do not give an anytime-valid global guarantee. The study does not establish field effectiveness, whole-machine or personnel safety. No new simulation was run during submission preparation.

## Verify and replay

Full release SHA-256: `11b577097cd937deb221c8b837b61ce7374d812b1fc7f48b0742329f5d61af21`.

Extract the complete release into a separate directory and run there with Python 3.10 or later:

    python analysis/t6_analysis_frozen.py --run-root T6_evidence --output-dir analysis_replay

The output directory must not already contain outputs. The analysis uses the Python standard library and includes 9,999 paired bootstrap replicates. This repeats the frozen statistical analysis, not the T6 scientific simulation. Source files in `frozen_source` and the original full release remain unchanged.

.NET SDK 8.0.424 is specified in `frozen_source/global.json` with roll-forward disabled. Project dependencies and test packages are recorded in project files; rebuilding additionally requires their restoration and the external .NET installation. The exact retained runtime/configuration authorities are in the full release. Do not treat a rebuild as a new authorization to rerun T6.
